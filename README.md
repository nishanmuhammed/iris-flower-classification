# 🌸 Iris Flower Classification

My first Machine Learning project! This project uses a
Decision Tree Classifier to predict Iris flower species
from their measurements.

## 🎯 Project Objective

Predict whether an Iris flower is:

- Iris setosa
- Iris versicolor
- Iris virginica

## 🛠️ Technologies Used

- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook
- Joblib

## 📊 Dataset

The Iris dataset contains 150 flower samples and four features:

- Sepal length
- Sepal width
- Petal length
- Petal width

## 🤖 Machine Learning Model

Algorithm: Decision Tree Classifier

Training samples: 120
Testing samples: 30

Test accuracy: 96.67%

## 📈 Evaluation

The model was evaluated using:

- Accuracy
- Precision
- Recall
- F1-score
- Confusion Matrix

## 🌱 Example Prediction

Input measurements:

[5.1, 3.5, 1.4, 0.2]

Predicted species: Iris setosa
